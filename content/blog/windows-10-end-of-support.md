## Find them

Make a list of every computer still on Windows 10, and check which ones can run Windows 11.

## Upgrade or replace

Upgrade the ones that can. Plan to replace the rest, starting with the computers that handle the most sensitive work.

## Bridge the gap

If you can't replace everything yet, paid extended updates can buy time, but they're a bridge, not a destination.
